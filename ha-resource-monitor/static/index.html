Jak czytać te dane?

Suma RAM obejmuje wyłącznie pozycje w tabeli, nie całe urządzenie. Nie uwzględnia wszystkich usług systemowych i pamięci podręcznej Linuksa. Integracje działające w Core nie mają osobnych pomiarów.

¹ RAM % pochodzi z Supervisora i odnosi się do limitu pamięci kontenera, nie sumy tabeli. Suma CPU nie jest pomiarem całego hosta i może przekraczać 100% na procesorze wielordzeniowym.

² Liczniki przesłanych danych, nie bieżąca prędkość transferu.

Co oznacza zużycie swapu?

Swap służy do przechowywania stron pamięci poza zwykłą pamięcią roboczą. Pokazujemy sumę aktywnego swapu widoczną dla jądra systemu, nie swap pojedynczej aplikacji. Może obejmować również zram, czyli skompresowaną pamięć w RAM.

Samo zajęcie swapu nie oznacza awarii ani bieżącego spowolnienia. Ten pomiar nie pokazuje tempa wymiany stron. Wartości swapu i sumy RAM aplikacji nie należy dodawać jako „całego zużycia RAM”. Panel nie zmienia ustawień swapu.
