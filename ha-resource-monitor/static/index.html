Jak czytać te dane?

Suma RAM obejmuje wyłącznie pozycje w tabeli, nie całe urządzenie. Nie uwzględnia wszystkich usług systemowych i pamięci podręcznej Linuksa. Integracje działające w Core nie mają osobnych pomiarów.

¹ RAM % pochodzi z Supervisora i odnosi się do limitu pamięci kontenera, nie sumy tabeli. Suma CPU nie jest pomiarem całego hosta i może przekraczać 100% na procesorze wielordzeniowym.

² Liczniki przesłanych danych, nie bieżąca prędkość transferu.
